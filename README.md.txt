
# WordCounter

## Описание проекта

Данная программа предназначена для подсчёта количества слов в строке.

Проект выполнен на языке программирования C#.

## Функциональность

Программа:
- Принимает строку от пользователя.
- Подсчитывает количество слов.
- Игнорирует множественные пробелы между словами.
- Корректно обрабатывает пробелы в начале и конце строки.
- Возвращает 0 для пустой строки.

## Пример работы

Ввод:
Hello   world

Результат:
Количество слов: 2

## Тестирование

Для проверки программы используется MSTest.

Реализовано 7 Unit-тестов:
1. Проверка двух слов.
2. Проверка одного слова.
3. Проверка нескольких пробелов.
4. Проверка пробелов в начале и конце строки.
5. Проверка пустой строки.
6. Проверка строки только из пробелов.
7. Проверка нескольких слов.

Все 7 тестов успешно пройдены.
